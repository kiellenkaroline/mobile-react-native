<summary>🛠️ Explicação do Layout Base</summary>
<p>Através do container (View) acoplei o layout que contém o Cabeçalho, Conteúdo Principal e o Rodapé. O container: <code>{ flex: 1 }</code> faz com que o container esteja centralizado na tela, com isso, fazendo ocupar todos os espaços disponíveis. <code>Flex: 1</code> faz com que o cabeçalho ocupe toda a parte superior da tela. os <code>backgroundColor</code> define a cor geral no Cabeçalho, Conteúdo Principal e do Rodapé. <code>JustifyContent</code> alinha o eixo vertical e <code>alignItems</code> o eixo horizontal.</p>

## Comandos necessários para rodar aplicação
- `npx create-expo-app@latest nome --template blank` (criar projeto do zero)
- `npm start` / **W** (WEB)
- `npx expo start --tunnel` (em caso de divergências na rede wifi)
- `npm start` (rodar projeto sem conflitos)
